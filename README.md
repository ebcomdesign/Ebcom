# اینفوگرافیک محصولات شرکت

مجموعه اینفوگرافیک‌های محصولات، در قالب یک وب‌سایت تک‌صفحه‌ای.

## مشاهده آنلاین

https://USERNAME.github.io/infographics-landing/

## ساختار پروژه

- `index.html` — صفحه اصلی (لندینگ)
- `assets/css/style.css` — استایل‌ها
- `assets/js/main.js` — اسکریپت‌ها
- `assets/images/` — تصاویر و لوگو
- `infographics/` — پوشه هر اینفوگرافیک
